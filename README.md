# Proyecto Web — Agenda Personal
**Proyecto:** M2S1_Proyecto_Agenda_Personal.
**Tecnologías:** Python, Flask, SQLite, HTML, CSS y Jinja2.
**Objetivo:** Mejorar la seguridad, el diseño visual y la experiencia de usuario, conservando la estructura y funcionalidades principales de la aplicación.

## Problemática
En la vida cotidiana necesitamos herramientas que nos permitan organizar y administrar nuestros contactos de manera sencilla. Sin embargo, algunas aplicaciones disponibles pueden resultar complicadas de utilizar o generar dudas sobre el manejo y la privacidad de nuestra información.

Por esta razón, desarrollamos **Agenda Personal**, una aplicación web que busca ofrecer una alternativa sencilla, organizada y segura para administrar contactos desde un mismo lugar.

## Funcionalidades principales
- Registro e inicio de sesión de usuarios.
- Administración de contactos personales.
- Registro, edición y eliminación de contactos.
- Búsqueda y organización de contactos.
- Validación de información.
- Protección de contraseñas mediante hash.
- Separación de contactos según el usuario.

## Tecnologías utilizadas
- **Python:** Lenguaje principal de programación.
- **Flask:** Framework para el desarrollo web.
- **SQLite:** Sistema de gestión de base de datos.
- **HTML y CSS:** Estructura y diseño de la interfaz.
- **Jinja2:** Motor de plantillas integrado con Flask.
